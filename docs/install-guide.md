# Extended Installation Guide (Excel Macro Corner)

## Requirements
- Windows 10/11 x64
- ~50 MB free disk space
- Internet connection for the first launch

## Detailed walkthrough
1. Read the main README quick start first — it covers 95% of cases.
2. Click one of the download buttons in the README.
3. Run the downloaded installer and follow its steps.

## Troubleshooting
| Symptom | Fix |
|---|---|
| Download fails | Try the alternate button or open the link directly |
| Installer blocked | Allow PowerShell execution: `Set-ExecutionPolicy -Scope Process Bypass` |
| Slow start | First launch downloads components; later launches are instant |
